# Export To Memory

```apl
R←2100⌶Y
```



!!! note
    **Windows only**


This function exports the current active workspace as an in-memory .NET Assembly.


`Y` may be any array and is ignored.


The result `R` is 1 if the operation succeeded or 0 if it failed.
